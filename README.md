# House Price Prediction with Generalized Linear Model (GLM)

This project focuses on predicting house prices using a Generalized Linear Model (GLM) approach in Python.

The analysis was conducted using selected explanatory variables from the Kaggle House Prices dataset. In order to create a more interpretable and simplified model, only the following housing characteristics were used:

- GrLivArea
- OverallQual
- YearBuilt
- TotalBsmtSF

The project includes:
- data preprocessing,
- missing value handling,
- logarithmic transformation,
- train-test split,
- GLM model construction,
- model evaluation,
- and coefficient interpretation.

Model performance was evaluated using:
- Pseudo R²
- Mean Absolute Error (MAE)

Results showed that the model achieved strong explanatory performance with relatively low prediction error.
